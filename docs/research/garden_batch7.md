### 3. フェイク前兆を考慮した立ち回り考察 (だくお, 2026/1/28)
【解析】内部モード別 規定あべし振り分け(設定1・設定変更後): 通常A主要=193-256 26.26% / 513-576 6.71% / 833-896 4.85% / 1217-1280 43.62%。通常B主要=193-256 32.72% / 321-384 5.41% / 705-768 1.19%…833-896 43.60%(通常B天井)。通常C=193-256 28.77% / 513-576 64.63%(実質天井)。天国=1-64 12.5% / 65-128 87.5%。
【解析】AT後(設定1): 通常A=193-256 21.94% / 1217-1280 10.99% / 1345-1408 15.11% / 1409-1472 29.30%(AT後は深い天井域あり) / 通常B=833-896 49.93% / 通常C=513-576 64.64%。
【解析】ゾーン別フェイク前兆発生率: 193-256・513-576・833-896等=「発生濃厚」(全モード) / 65-128=50% / **321-384=通常Aで10%以下・通常B/Cで50%**（=通常B以上示唆） / 1-64,129-192,257-320,385-512でのフェイク前兆発生=**通常B以上確定**。
- 期待値考察: 通常B以上確定なら残り平均<500あべしでどの状況でも続行。321-384フェイク発生時も384から残り平均約500あべしで続行可(当選率3%以下のゾーン)。示唆なし台を384以降から打つと示唆不問比で約-1500円。
- **あべし換算に関する記述**: 「1Gあたり平均2あべし換算」を明示（記事内のざっくり計算基準）。実ゲーム数が同あべし数なら少ないほうが期待値高(前任者がモード示唆を確認できていないため)。天破中に貯めたあべしで通過したゾーンはフェイク前兆確認不可。
- 設定変更後は0あべし開始と256あべし開始で平均残りあべしがほぼ同等、リセット後0Gから256あべしまでの出玉率は実戦値約100.5%。
→カウンター判別: モード推測は液晶前兆依存でカウンター単体では不可(参考)。ただしリセ後カウンター約123G(≒256あべし)以内当選が多い日はリセ+高設定域の傾向としてresetZonesの根拠に使える。あべし2.08倍換算はこの記事では「約2あべし/G」と丸められている点に注意。

### 7. 北斗転生2シャッター狙い完全ガイド (そー, 2026/3/8, 約25000字)
- ゲーム数前兆は各ゾーン**後半32あべし以内でしか発生しない**(256ゾーンなら224-256のみ)。ゾーン外前兆は「896以内当選なら全ゾーン必ず発生 / 896抜けなら一切発生しない」の0:100。

【実戦vs解析】規定あべしの設定差(低設定理論値vs設定56実戦値): 1-128あべし 約8→13% / 256・576はほぼ差なし / **705-896あべし 約19→34%** / **896抜け率 約32→8%**。

- 新説「モードが無い」: 実質あべし選択率のみで管理され、通常A/B/Cはサブ基板の演出上の逆算にすぎない可能性(257あべし以降の当選期待度がモード不問で一致・ゾーン外天命移行率実戦11.7%がモード理論値7.4%を超過)。→設定判別は**当選あべし数だけメモすれば成立**、モード監視不要。

→カウンター判別: **905-896境界の当選あべし比率が最強の設定判別軸**。カウンターG換算では705-896あべし≒カウンター約339-431G、896抜け≒約431G超のハマり。「431G超ハマり回数 vs 339-431G当選回数」の比率チェックがzones/checksとして実装可能(低設定は抜け優勢63%、高設定は19%)。
