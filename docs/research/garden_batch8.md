## 記事4: 有利切断条件と有利切れ狙いの考察 (2026/5/1公開)
【実戦】+考察。有利差枚+2200枚でエンディング(だが多くはシームレスに有利切れ)
- 有利切れにはATストック数が関係: ストック保持中でないと切れにくい/一定ストック以下まで放出してから切れる、と仮定すると挙動と整合
- 有利切れ後は必ず2連以上(Gゾーン最終G当選の1セット目+ループストック)。エンディング後にGゾーン最終G以外当選や単発の挙動は未確認
- 最高差枚更新時差枚別の2→3連継続率(N=5886): 1-201枚 47.3% / 401-601枚 44.5% / 801-1001枚 48.2% / 1001-1201枚 51.4% / 1201-1401枚 56.0% / 1401-1601枚 62.5% / 1601-1801枚 66.7% / 1801-2001枚 76.9% / 2001-2201枚 86.6% / 2201-2401枚 84.5%。→差枚1000枚超で有利切れ抽選優遇(継続率上昇=切れ後強制2連以上のため)
- 「差枚+1000超えてから2セット以上継続したAT」は有利切れ済みの可能性大。逆に2連以下で終了したATは有利切れしていない可能性大
- 差枚マイナスでも有利切れが起こることがある
→カウンター使い道: 履歴の連チャン形状+当日差枚から有利切れ推定が可能(切れ後は差枚リセット扱いで状態評価をリセット)。「Gゾーン=スタート6G表示」の当選が連続する履歴はAT継続中の分割表示として扱う必要あり

## 記事5: 有利切れ狙い徹底解説～差枚を制する者は神をも制する～ (2026/5/18公開, 6/10更新)
【実戦】「最低有利差枚」概念の解説記事
- 前回AT終了時有利差枚別出率(当日有利切れなし台): <1000枚 1/444・608枚・93.5%(N=177737) / 1000-1200 1/422・708枚・101.3% / 1200-1400 1/391・795枚・109.7% / 1400-1600 1/445・873枚・108.0% / 1600-1800 1/406・1160枚・126.6% / 1800-2000 1/373・1233枚・134.6%(N=45)
- 有利切れ恩恵=2個以上ストック確定(エンディング後60/60件で2連以上)。切れ後1セット目=Gゾーン最終G当選100%(60件、筐体表示5G/データランプは多くが6G表示、店により5G)。2セット目=Gゾーン内当選100%(告知G振分: 1G 20%/2G 8%/3G 7%/4G 17%/5G 48%)、潜伏なし
- 履歴判別ルール: 「Gゾーン最終G以外(≠6G)当選なら前セット終了時に有利切れなし」「潜伏(7G+)当選なら前・前々セット終了時とも有利切れなし」→最低有利差枚を過去に遡って積算可能
- SGG中エンディング判別: BB信号後に6GのART信号(通常は0G)。GG中エンディング: Z-ZONE/GOD非経由でAT中56G+消化→次セットGゾーン最終G当選
- SGG終了時差枚別のAT2連以上率(有利切れ発生率の代理、N=6013): <0枚 20.9% / 600-800 20.8% / 800-1000 31.9% / 1000-1200 40.8% / 1400-1600 63.2% / 1800-2000 85.3% / 2000枚+ 100%。→+800枚から切断抽選、+2000枚で確定切断
- 有利切れ条件推定: 「有利差枚+800以上 かつ 残ストック2個以下」で切断抽選。例外(マイナス差枚切断=据置疑い、+2000付近非切断)あり
- ゾーン当選率(41-400Gの20G刻み): 非有利切れ後 5.0%→4.0%と緩やか減。有利切れ後疑い台は4.4%→3.7%と全体的に低い(天国非引継ぎ+冷遇解除で初当り重の影響)
- 最低有利差枚別期待値: 非切れ台+1200枚以上→+1000下回るまで打てる(出率105-113%)。切れ疑い台は+1400枚以上から
→カウンター使い道: 有利切れ検出ロジックそのもの(6G/潜伏の並び+差枚+800/2000閾値+2連保証)。アプリで「同一有利区間の最低差枚」を履歴から自動積算すれば状態推定精度が大幅向上

## 記事1: 実戦データから優遇挙動を考察 (2025/11/24公開, 12/6更新)

→カウンター使い道: 周期=ポイント制でカウンターG数と非直結だが、0スルー台のCZ間G数分布(周期数)から優遇状態の推定材料になる(浅い間隔で当たり続ける0スルー台は優遇継続中)
