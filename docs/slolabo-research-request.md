# すろらぼ深掘り調査依頼(コピペ用)

高設定チェッカーの判定ルールを作るための調査依頼文。
すろらぼ(slolaboratory.com)にログインした状態のブラウザ/リサーチAIに、下の「----ここから----」以降を貼って使う。
機種数が多いので、機種リストを25機種ずつ程度に分けて複数回に分けて依頼し、結果はGoogleドキュメントにまとめてもらうと取り込みやすい。

----ここから----

あなたにはスロット設定判別サイト「すろらぼ(slolaboratory.com)」を使った調査を依頼します。
目的は、パチンコ店のデータカウンター(見えるのは「総ゲーム数・大当り履歴〈何G目に当選/獲得枚数/BB・RB種別/時刻〉・BB回数・RB回数・合成確率」だけ)から設定を推測するアプリの判定ルールを作ることです。

## 最重要の注意(前回調査の反省点)

前回の調査は「設定別の初当り確率」だけを拾った表面的なもので不足でした。今回は各機種について、すろらぼ内の**その機種に関するページを全部開いて**ください。具体的には:

- 設定判別・設定差まとめページ
- 天井・ゾーン・ハイエナ期待値ページ(**仮天井・短縮天井・モード別天井**と、**前兆の最大ゲーム数**=当選が履歴上何Gまで後ろにズレて表示されるか、を必ず)
- モード・内部状態の解説ページ
- リセット(設定変更時)と据え置き時の挙動ページ
- 実践データ・大量サンプル集計記事(あれば設定別の実測値とサンプル数)
- 機械割・スペック解説ページ

1ページの「まとめ表」だけ見て済ませず、リンク先の個別記事まで読んでください。

## 各機種について報告してほしい項目

数値は必ず「設定1: 〜 設定6: 〜」の形で全設定分、表記(1/xxx か % か)もサイトの記載のまま書き写してください。**その数値が何の確率なのか(何を分母にした何の当選か)を必ず一行で添えてください**(前回、別の数値〈ベル集中など〉を初当り確率と取り違える事故がありました)。サイトに記載がない項目は空欄にせず「記載なし」と明記してください(ゼロと未記載の区別が重要です)。解析値か実践値かも区別し、実践値はサンプル数も書いてください。

1. **初当り確率(設定別)** — ボーナス機はBB/RB別。AT機はCZ確率とAT初当り確率を区別
2. **AT・ボーナス直撃確率(設定別)** — CZを経由しない当選。データ履歴上どう見えるか(RB表示になる等)も分かれば
3. **ゾーン・モード** — 当選しやすいG数帯(解析・実践両方)、モード移行率の設定差、モード別天井G数
4. **天井まわり** — 本天井G数/仮天井・短縮天井とその振り分け設定差/**前兆の最大G数**/天井恩恵
5. **AT・ボーナスの出玉性能** — 平均獲得枚数、単発率、継続率、上位AT・エピソード・特化ゾーン(例: ハラキリドライブのような大量出玉トリガー)への突入率の設定差。「1回の当選でまとまった枚数が出たかどうか」で設定を見抜ける要素を重点的に
6. **連チャン・引き戻し・天国** — 天国移行率の設定差、引き戻し区間(何G以内の再当選が天国由来と判断できるか)
7. **REG率・ボーナス比率** — Aタイプ・ボーナストリガー機はREG確率と合成に占めるREG比率の設定差
8. **リセット/据え置き挙動** — 設定変更時の内部状態(天井短縮・モードリセット・朝イチゾーン)、据え置き時との違い。宵越しG数の扱い
9. **設定示唆・確定パターンのうちデータカウンターだけで判別可能なもの** — 特定G数当選、獲得枚数表示、履歴の並びなど。(液晶演出・ボイス・トロフィー等カウンターで見えないものは「参考」として分けて記載)
10. **その機種で最も設定差が大きい判別要素トップ3** — サイトが「判別の急所」としている要素を、カウンターで読めるかどうかの区分つきで

## 出力形式

機種ごとに以下のテンプレートで(Googleドキュメントに追記):

```
■ 機種名(正式名)
【初当り】設定1: … 設定6: …(何の確率か)
【直撃】…
【ゾーン/モード】…
【天井】本天井: … 仮天井/短縮: … 前兆最大: …G 恩恵: …
【出玉性能】平均獲得: … 単発率: … 上位突入率: 設定1: …→設定6: …
【連チャン/天国】…
【REG比率】…
【リセット/据え置き】…
【カウンター判別可能な示唆】…
【判別の急所トップ3】1. …(カウンター可/不可) 2. … 3. …
【出典ページ】読んだ記事タイトルを列挙
```

要約や省略はせず、数値はサイト記載のまま。似た機種でも1機種ずつ全項目を埋めてください。
