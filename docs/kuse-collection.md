## 横展開候補（越谷近隣・Xでヒント＋答えが取れる店、2026-08-21調査）
基準は「前日ヒント役」と「事後の答え役」の両方がXにいること。近い順:

1. **ピーアーク越谷**（越谷市内・最有力）— ヒント: @slot_channel_（前日にローテ/過去傾向/狙い目、例: 3台以上機種に全台系・東京喰種10%以上で上2つ・ゴッド/からくり2/ヴヴヴ2）。答え: @kata_sainokuni 塊（結果精査: 並び箇所数・1BOX・抽選人数・PICK率）
2. **ピーアーク草加**（草加市）— 同じ2アカウントがカバー（8/15結果: 6~8台並び×6・2BOX+3.0）。イベント告知は @onigiri_slot も
3. **パラッツォ三郷中央**（三郷市）— ヒント: @toraena_（機種名まで指定、例: Lカバ&ヴヴヴ2が1/2で上2つ）。答え: @sloinfo_saitama（結果速報＋毎日仕掛けの覚書 #パラミサ覚書）
4. **ガーデン八潮**（八潮市）— イベシル店別結果（列全・12台並び）＋いけちん来店取材。athink実データ照合も可（tenpo_id=yashio）

補助アカウント: @777mine0（埼玉県オススメホールランキング毎日）、@kachigumimax（抽選人数まとめ）

注: 実データ照合(チェッカー本体)がそのまま動くのはathink対応のガーデン系のみ。ピーアーク/パラッツォはまず「くせ読みDBのみ」で始め、データ照合は各社の公式データ公開(ピーくんタウン等)を導入時に調査する

## 必須ルール
1. **イベシルの詳細画像ポストは絶対に取り逃さない。** 店名付きで定期発表される。画像URL（pbs.twimg.com/media/…）を posts_raw.json に保存し、画像から台番・機種名・G数・差枚を読み取って events.json の `dai_detail` に反映する（columns: [台番, G数, 差枚]）。画像はURL失効に備えて data/kuse/img/{date}_{n}.jpg にも保存する
2. 結果ポストは前日ヒントを引用していることが多い。引用先IDも記録する
3. 原文は必ず posts_raw.json に残す（構造化に失敗しても後で再パースできるように）

## 運用（2026-08-21決定）
- **手動トリガーのみ**（定期実行なし）。ユーザーが「くせ読み更新して」等と言ったときに収集する。打ちに行く前日/当日朝の依頼を想定
- 収集時は主要2アカウントに加えて、**`ガーデン川口安行 M/D` の全体検索**（例: `ガーデン川口安行 8/21`）で他のアカウントの晒し・実戦報告も拾う。有望なアカウントを見つけたら本ファイルの情報源に追記する

## 収集方法（検証済み 2026-08-21）
- 検索: `from:eveshiru 安行` / `from:ikechinpachislo 安行` ＋ 全体検索 `ガーデン川口安行 M/D` を「最新」タブで。期間指定は `since:YYYY-MM-DD until:YYYY-MM-DD`
- **Xの検索はすぐスロットルされる**（結果の間引き→空、内部APIは404）。1晩の収集は検索2〜3回＋新規ポストの個別ページ閲覧数件に留める。個別ポストページ（/status/ID）はスロットル対象外で安定
- 機種名を正しく取るためXの表示言語は日本語のままにする（英語だと自動翻訳で機種名が壊れる。lang=jaパラメータでは回避不可）
- DOM抽出: `article[data-testid="tweet"]` 内の `[data-testid="tweetText"]`、`time[datetime]`、`img[src*="pbs.twimg.com/media"]`。タイムライン表示は長文が省略されるので、全文は個別ページで取る

## 判明しているくせ（2026-08-21時点、標本4イベント）
- **月ゾロ日はガーデン全23店で「今月の機種」を全店仕掛け**（集大成Z取材）: 5/5=化物語(120台/勝率75%)、6/6=マギレコ(114台/勝率87.7%)、7/7=ヴヴヴ2(184台/勝率62.5%)、8/8=東京喰種(358台/勝率79.0%)。9/9の対象機種は前日のイベシル告知で確認すること
- Lハナビが全系常連（4回中3回）
- 「Sammy機種に必ず」系のヒント頻出（このすば・ヴェンデッタ・カバネリ等で回収）
- GODは1/3配分が定番（全ツッパ非推奨、オススメ表記でも1/3）
- 毎月17日=月周年日。四賢者=マギレコ/喰種/L炎炎2/化物語で「基本は化物語or炎炎」
- 旧イベ日はピック率14〜21%、全1機種+全系2〜3機種+1/2×1+1/3×3前後が型

## ヒント用語の定義（ユーザー確認済み 2026-08-22）
- **「ゾロ目末尾1/3上2つ」** = 下2桁がゾロ目の台（x11, x22, …, x99。x00は含めない想定。安行では約50台）**全体のうち約1/3**が設定5・6、の意味。「当日の日付と同じゾロ目」でも「特定の1グループ」でも**ない**。ゾロ目台は店内平均より事前確率が高い（約33% vs 10%）ので、判定が中程度でもゾロ目なら格上げして見る。
