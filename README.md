# 高設定チェッカー(slot-app)

店舗WiFi限定のデータサイト(athink.jp)からスロットの台データを収集し、
高設定挙動の台をその場で見つけるための個人用ツール。

- **閲覧ページ**: https://iga89koshi-art.github.io/slot-app/ (GitHub Pages)
- 収集は店内のスマホでブックマークレットを実行(下記)

## 構成

```
[店内・スマホ]                                 [このリポジトリ]
データサイトを開く                              data/ に日別スナップショット
  ↓ ブックマークレット(collect/)                 index.html が閲覧ページ(Pages公開)
  全台自動巡回 → その場で高設定候補ランキング表示
  ↓ JSONコピー(または GAS 自動蓄積)
  蓄積 → 据え置き・日別比較(閲覧ページ)
```

## 機能

- **収集**: 機種一覧→台一覧→台詳細(BB/RB/確率/大当り履歴)を自動巡回
- **その場の分析表示**(収集直後のスマホ画面):
  - ジャグラー: 設定1〜6のベイズ事後確率 → 高設定(設5・6)確率ランキング
  - AT機: 連チャンを一塊にした初当り確率を同機種内比較(優秀度z値)
  - 機種別サマリー: 全台系候補(★)・1/2配分候補(☆)の検出
  - 並び検出: 好調台の並び・「挟まれ台」など座り目候補の提案
  - ヒント貼付: 晒屋のXポストを貼るとその場で解読して該当台×実データ表示
- **閲覧ページ**(index.html): 保存済みスナップショットの分析表示+収集JSONの貼り付け分析

## セットアップ

### 収集ブックマークレット(初回のみ)

1. スマホのブラウザで適当なページをブックマーク登録(名前:「スロット収集」など)
2. ブックマークのURL欄を `collect/loader.bookmarklet.txt` の1行に置き換える

ローダー方式のため、ツール更新時もブックマークの貼り替えは不要。

### GAS(任意・自動蓄積用)

`gas/code.gs` をスプレッドシートのApps Scriptに貼り付けてウェブアプリとして
デプロイし、収集ブックマークレット初回実行時にURLを入力する。詳細はファイル内コメント。

## 使い方(毎日)

1. 店内でデータサイトを開き「スロット収集」をタップ(全機種3〜5分)
2. その場でランキング・機種サマリー・座り目候補を確認
3. 晒しポストがある日は「ヒント貼付」に貼って該当台×実データを確認
4. データを残す場合はJSONコピー(閲覧ページの貼り付け分析でも見られる)

### 収集を続ける(任意・収集完了後に出るボタン)

- **🔁 15分ごとに自動収集**: 店に滞在中、タブを開いたまま置いておくと15分間隔で
  自動再収集してアップする(打ちながら時系列データが貯まる)。画面スリープはOFFにする。
  「中止/閉じる」で停止。
- **⏪ 過去6日分をバックフィル**: データサイトの日付指定APIで過去日をまとめて収集(20〜30分)。
  保存済みの日は自動スキップ。数日ぶりの来店でも空白日を埋められる。

※データサイトのAPIは店舗WiFiのIPからしか応答しないため、店外・自宅からの
自動収集は不可(2026-08検証済み: 店外からは401)。上記2機能はその制約内での代替手段。

## ファイル構成

- `index.html` … 閲覧ページ(GitHub Pages)
- `collect/collector.source.js` … 収集+分析本体(ローダーが毎回これを読む)
- `collect/loader.bookmarklet.txt` … ブックマーク登録用の1行
- `collect/hints.json` … 当日のヒント(晒し情報の解読結果)
- `collect/copy-html.*` … サイト解析用のHTMLコピーツール
- `analyze/` … Node製の分析スクリプト(開発用)と機種スペック
- `gas/code.gs` … GASバックエンド(任意)
- `data/` … 日別スナップショット(index.jsonが一覧)
- `samples/` … データサイトのHTMLサンプル(パーサー検証用)

## 注意

- 個人利用目的。データサイトへのアクセスは節度あるペース(200ms間隔)に制御
- 確率表示はデータ由来の推定値であり、設定を保証するものではない
